### Fixed
- Workers AI continuation now uses the same structural/canonical runtime publication authority as Gemini: bounded novelty and Phase-2 scores remain prompt/eval signals but no longer turn a structurally valid Scene into `invalid_generation` after a Branch is committed. Malformed provider shape, invalid/repeated Scene or Choice structure, spoken-length violations, and missing/non-distinct/unsupported provider-authored durable facts still fail closed.
- Artwork-backed narrative copy now uses shared 0.58 strong and 0.34 glass scrims plus one restrained text-shadow contract, revealing substantially more Scene artwork across Home, Library, reading, consequence, recap, and generation surfaces while retaining text contrast.
- Choice commitment now treats a thread resolved by both the Scene transition and the selected branch as one logical resolution, so already-published Scenes with that valid overlap can commit instead of returning an internal error; genuinely unknown canonical keys still fail closed. Expanding mobile Scene tools now scrolls the newly revealed voice and share controls into view instead of leaving them below the current viewport.
- AI suggestion names now obey the same normalized 2–50 character contract across provider schema, API cache/replay validation, live mobile parsing, and preview; one-character partially typed names are omitted as optional inspiration rather than allowing an unusable cached batch. Preview inspiration truncation is Unicode code-point safe, so boundary emoji are never split. Suggestion provider work is bounded by a 24-second total deadline under a 35-second D1 lease, UTC-day quota is recomputed at atomic finalization to close the midnight race, and malformed ready-cache DTOs fail closed.
- Daily sparks no longer create another canonical Drama when the finite prompt catalog cycles: Home resolves an already-used prompt to the owner’s newest active matching Drama—even outside the recent shelf—and opens its current Scene; hidden resume targets now use truthful generic resume copy instead of new-Drama labels. Mobile persists the pending normalized draft fingerprint plus both the Scene-1 creation key and first-generation key across remounts when SecureStore succeeds, upgrades legacy v1 pending records without replacing their creation key, while explicit custom Dramas remain independent and Library rows are never hidden by title-only deduplication.
- Development Workers keep the optional Analytics Engine binding absent until the Cloudflare account feature is enabled; generation telemetry remains fail-open and canonical Scene behavior is unchanged.
- iOS is now contract-locked to system `NativeTabs` with native `onScrollDown` minimization; the unsigned IPA job runs explicitly on macOS 26 and rejects Xcode older than 26 so iOS 26 Liquid Glass cannot silently fall back to the custom Android/web rail.
- Responsive web now uses the same bottom glass navigation owner as Android instead of rendering NativeTabs as a top rail; scroll intent shrinks 390×68 to the 248×46 icon rail, nested Library routes return to the Library root when its active tab is pressed, and bottom content insets track the active rail.
- Removed nested interactive controls that rendered web `<button>` elements inside other buttons: Scene tap-to-advance is now a sibling hit target beside beat selectors, and Library row open/pause actions are sibling controls. This eliminates hydration errors without changing playback or archive state.
- Removed the unsafe Scene-generation concessions that derived missing `durableFact` text from provider labels/consequences and accepted drafts rejected only by novelty/publication rules. Missing primary branch material now enters provider-authored targeted repair, repair responses require it, and the complete structural + narrative publication decision remains authoritative.
- Scene generation now uses one slim 8B creative call (`@cf/meta/llama-3.1-8b-instruct-fast`, 2300 tokens, no `stateDelta` in schema) on the happy path; malformed first output retries with one full creative regeneration, and publication rejections that do not require rewriting `script` use a smaller targeted-repair schema (1200 tokens, no `script`, byte-for-byte script preservation) before `invalid_response`; provider exceptions remain `provider_unavailable`; no server-side invented narrative facts/relationships/threads, and durable branch facts are provider-authored, branch-specific, non-placeholder, and consequence-supported.
- Resolved fact/thread tombstones now scan canonical committed history for the latest unique entries, block exact resurrection while remaining bounded at 24+24, and survive through the 50-Scene soak; old `script_json` rows without `beat`/`pacingRole`/`motifSignature` stay readable.
- Generation context is strictly bounded (`recentHistory` ≤4, `activeFacts` ≤24, `openThreads` ≤12, `relationships` ≤20, `novelty` ≤4/20/12, `arcMemory` ≤3, `resolvedMemory` ≤24+24) so 50-scene context bytes plateau instead of growing linearly; checkpoint failure never invalidates a successful canonical commit.
- Telemetry and checkpoint writes are fail-open and never change canonical behavior.
- Scene create/continue requests now allow the backend’s controlled generation path (one 8B call + at most one repair/regeneration) up to a 120-second defensive client ceiling before abort; timeout copy is defensive-specific (generation key preserved safely) and does not claim expected p50/p95 without live measurement.
- One-character Scene continuation now constrains structured output to valid durable branches, preventing impossible relationship deltas from being stripped into `invalid_generation` after retry.
- Scene generation no longer fails after a daily text threshold; generated Scenes remain fully ledgered for idempotency/reconciliation, while fresh-voice limits stay server-enforced outside the development preview. Home exposes resource-specific enforcement so mobile can show unlimited Scenes without misreporting voice quota.
- Publication authority no longer rejects on eval-only dimensions; CRITICAL_THREAD_STALLED is eval-only (not per-thread age); Workers AI now runs the same narrative publication gate as Gemini.
